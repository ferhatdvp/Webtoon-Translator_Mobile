Nasıl kullanılır?

İlk kullanım

  1. ⋮ → Ayarlar bölümünden Gemini API anahtarını gir, ücretsiz katman onayını işaretle ve bağlantıyı test edip kaydet. API anahtarını Google AI Studio üzerinden alabilirsin.
  2. Adres çubuğuna webtoon sitesini yaz. Site açılınca ⋮ → Bu siteyi çeviri listesine ekle seçeneğine dokun.
  3. Bir bölüm aç. “Çevriliyor…” yazısının ardından Türkçe metinler görsellerin üzerinde görünür. Yazıya dokunduğunda İngilizce orijinali birkaç saniye görünür. TR düğmesi çeviriyi gizler veya gösterir.
  4. ⋮ → AFK modunu başlat seçeneği, çeviriler tamamlandıkça sayfayı kaydırır ve uygun bir sonraki bölüm bağlantısını izler. Ekrandaki küçük pencere simgeli yuvarlak düğmeyle istediğin zaman küçük pencereye geçebilirsin. Büyüttükten sonra aynı düğmeyle tekrar küçültebilirsin. TR ve küçültme düğmelerini sürükleyerek yerlerini değiştirebilirsin; bıraktığında hafifçe kayıp dururlar ve son konumları hatırlanır.
